# deploy/kz: шаблоны для сервера в Казахстане

Подготовлено, **не применено**. Описание, схема и порядок развёртывания: `docs/platform/ADMIN-ISOLATION-KZ.md`.

| Каталог | Что внутри |
|---|---|
| `wireguard/` | сервер `wg0`, пример конфигурации устройства, `wg-staff.sh` (добавить/отозвать/перечислить/восстановить устройства) |
| `nginx/` | публичный API-хост, админка только на адресе VPN, общие настройки прокси и TLS |
| `nftables/` | firewall: drop по умолчанию |
| `postgres/` | `listen_addresses`, `pg_hba.conf` |
| `systemd/` | `bb-admin`, `bb-api`, таймер уведомлений, восстановление VPN-пиров |
| `env/` | примеры окружения для админки, API и Vercel-сайта (секреты только маркерами) |
| `dns/` | split-DNS только для VPN |
| `backup/` | pgBackRest: отдельные задания на каждое из двух внешних хранилищ, ежедневная проверка обоих, тренировка восстановления из каждого, алерт без ПДн |
| `scripts/` | `render.sh` (подстановка адресов), `verify-isolation.sh` (проверка «снаружи» и «внутри VPN») |

Шаблоны `*.template` содержат маркеры вида `@ADMIN_HOST@`. Они заполняются `render.sh` из файла `deploy.env`
(домены, адреса, порты; без секретов, файл не коммитится). В репозитории нет ни одного настоящего домена админки, адреса или ключа.
Тесты: `platform/tests/deploy-kz.test.ts`.
