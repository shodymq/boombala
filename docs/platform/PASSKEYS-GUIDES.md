# Face ID / Touch ID: инструкции

## Владельцу (Owner)
**Один раз, при запуске**
1. Войдите по паролю и коду. «Мой пароль» → «Добавить это устройство» → подтвердите кодом из приложения → Face ID / Touch ID. Добавьте второе устройство (Mac или аппаратный ключ) и убедитесь, что есть коды восстановления (хранить отдельно от телефона).
2. Заведите **второго Owner'а** (человек, которому доверяете): если потеряете всё, он вас восстановит.

**Новый сотрудник (менеджер, кассир)**
1. «Сотрудники» → создать (имя, e-mail, роль «Менеджер», временный пароль, передайте лично).
2. Там же у сотрудника «Выдать код настройки» → подтвердите себя кодом/ключом → **покажите код сотруднику лично** (виден один раз, действует 2 часа).
3. Сотрудник входит с паролем, вводит код, включает приложение-аутентификатор, записывает коды восстановления, затем добавляет Face ID / Touch ID.

**Потерян телефон у сотрудника:** «Сотрудники» → «Отозвать все ключи» (подтвердить) → он войдёт по паролю и коду и добавит новый. Если потерял и приложение: «Сбросить второй фактор» → «Выдать код настройки».
**Сотрудник уволился:** «Отключить» и «Отозвать все ключи».
**Вы сами потеряли всё:** второй Owner делает то же для вас; если Owner один, администратор сервера: `user:mfa-reset`, затем `user:enrollment-code` (см. PASSKEYS.md).
**Правило:** никому не называйте свой пароль и коды; код настройки выдаётся только лично и только тому, кого знаете.

## Кассиру и менеджеру
**Вход (после первой настройки)**
1. Подключитесь к VPN (WireGuard). Откройте `https://crm.boombala.kz`.
2. Нажмите **«Войти с Face ID / Touch ID»** и подтвердите лицом или отпечатком.
3. Работайте в «Посещаемости» (поиск, «Подтвердить вход»).
**Смена сотрудника на общем планшете:** «Выйти». Следующий сотрудник входит **своим телефоном**: «Войти с Face ID / Touch ID» → «Использовать другое устройство / Scan QR code» → подтвердить на своём iPhone. Не добавляйте ключи на планшет кассы.
**Не получается войти ключом:** войдите по e-mail, паролю и коду из приложения (или коду восстановления); если и так не выходит — позвоните владельцу.
**Новое устройство:** «Мой пароль» → «Добавить это устройство» → подтвердить кодом из приложения.
**Потеряли телефон:** сразу сообщите владельцу, он отзовёт ключи.
