# QR-регистрация: телефон необязателен

Решение: телефон сопровождающего в QR-форме `/consent` необязателен (экстренная связь). Меняется только QR-регистрация.
Заявки на дни рождения и ручные брони по-прежнему требуют телефон: это закреплено не только в приложении, но и в БД.

## Правила
- Поле пустое → регистрация проходит, номер не сохраняется (`contacts.phone_e164 = NULL`). Фиктивные номера не подставляются.
- Поле заполнено → формат проверяется (`+7` и 10 цифр на сайте; сервер принимает также нормализуемые международные номера). Неверный номер → 400 `fieldErrors.phone`, ничего не сохраняется.
- Контакт без номера **никогда не объединяется** с другими, в том числе по имени: ключ `UNIQUE (phone_e164, name_key)` считает `NULL` различными значениями, поэтому каждая регистрация без номера — отдельный контакт. Два посетителя с одним именем не сливаются.
- Контакт с номером ведёт себя как раньше: тот же номер и то же имя (без учёта регистра и пробелов) — один контакт; тот же номер с другим именем — отдельный контакт, в CRM видно «этот номер ещё у N контактов».
- Для контакта без номера в CRM пишется «не указан» / «без телефона», группа «тот же номер» пуста, в выгрузке ячейка телефона пустая.

## Что не меняется
- Две отдельные галочки: ознакомление с правилами и согласие на обработку персональных данных (обе обязательны).
- История согласий: по одной записи `consent_events` на каждую принятую версию документа, привязка к регистрации.
- Идемпотентность по ключу: повтор и параллельные отправки одного ключа дают одну регистрацию. Для запросов с одним ключом добавлена транзакционная advisory-блокировка, чтобы проигравшие параллельные запросы не оставляли «осиротевших» контактов без номера (без номера их нечем склеить).
- Юридические тексты и требования к ФИО не менялись и не публиковались: их утверждает юрист отдельно. Документы (правила посещения, видеонаблюдение, документы на аттракционы, школьные группы) этой правкой не затрагиваются.

## Миграция
`platform/migrations/008_optional_qr_phone.sql`: `phone_e164` допускает `NULL`; `CHECK (phone_e164 IS NOT NULL OR source = 'qr')` — номер обязателен для всех источников, кроме `qr`. Применять к реальной БД только после подтверждения.
