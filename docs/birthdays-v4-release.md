## Шаги выпуска (платформа, затем сайт)
0. Снимок каталога до релиза: `npm run catalog:snapshot -- /secure/path/catalog-before.json`.
1. Резервная копия БД и проверка копии.
2. `npm run db:migrate` (015 — маркер, данные не меняет).
3. `npm run db:seed` — три новых пакета и их цены V4 (только на пустой каталог; в базе с уже записанными V3-ценами цены надо поменять через `setPriceRule`, append-only).
4. `npm run db:roles`, затем `npm run preflight` — должен быть `OK`.
5. Деплой сайта V4.
6. Тестовые заявки «ТЕСТ» на три пакета на живом окружении; проверка уведомления менеджеру.
7. `npm run catalog:retire-legacy`, затем `npm run preflight:final` — должен быть `OK`.

## Откат
1. Старый деплой сайта.
2. `npm run catalog:restore -- /secure/path/catalog-before.json --deactivate-current` (только флаги продажи; бронирования и цены не удаляются и не пересчитываются).
