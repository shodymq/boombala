# Форма «Забронировать праздник»: ручная проверка на реальных телефонах

Автоматические проверки (`npm run test:lead-form`) идут в Chromium с эмуляцией экрана и касаний. Это **не Safari и не реальный телефон**: клавиатуру, панели браузера и системный выбор даты iOS они воспроизвести не могут. Эти пункты нужно посмотреть руками на странице `/birthdays` (Preview-сборка этой ветки).

## iPhone, Safari (по возможности и маленький SE, и большой Pro/Max с Dynamic Island)
- [ ] Открыть форму: лист поднимается снизу, под вырезом/островом остаётся зазор, ширина ровно по экрану, горизонтального сдвига нет.
- [ ] Потянуть за затемнённый фон и за пустое место: страница позади не двигается.
- [ ] Прокрутить форму пальцем: двигается только содержимое, заголовок и кнопка «Отправить заявку» остаются на месте. Резиновый «отскок» не тянет за собой страницу.
- [ ] Коснуться полей «Ваше имя», «Телефон», «Количество детей»: клавиатура выезжает без прыжков и зума, активное поле не закрыто клавиатурой, после закрытия клавиатуры лист на месте.
- [ ] Свернуть/развернуть адресную панель Safari (прокруткой внутри формы и жестом): верхний край листа не смещается.
- [ ] Поле «Желаемая дата»: подпись показывает русскую дату («сб, 19 декабря 2026 г.») даже при английском языке iPhone; системное колесо выбора даты открывается по касанию, после выбора подпись обновляется.
- [ ] «Пакет праздника» и «Предпочитаемая комната»: открываются списком карточек внутри формы (без системного колеса), выбор закрывает список, поле показывает выбранное. У комнат видны маленькие обложки.
- [ ] Отправить пустую форму: ошибки видны, фокус на первом неверном поле. Отправить правильную: «Заявка отправлена».
- [ ] Закрыть крестиком, нажатием на фон, повторно открыть: страница на том же месте, форма чистая.
- [ ] Галерея комнат (карточка комнаты): лист стабилен так же, видео запускается по нажатию, «Узнать о бронировании» открывает форму с уже выбранной комнатой.
- [ ] Повернуть телефон в альбомную ориентацию: кнопка «Отправить заявку» остаётся на экране, форма прокручивается.
- [ ] VoiceOver (по желанию): поля читаются с названиями, списки «Пакет»/«Комната» читаются как список с выбранным пунктом.

## Android, Chrome (по возможности Pixel и Samsung)
- [ ] Те же пункты, что для iPhone.
- [ ] Клавиатура: при открытии высота экрана уменьшается, лист остаётся с тем же верхним зазором, кнопка «Отправить заявку» видна над клавиатурой; на очень низком экране блок WhatsApp уходит в конец прокручиваемой части.
- [ ] Кнопка «Назад» на Android: запомнить, что она делает (закрывает лист или уходит со страницы), и сообщить.
- [ ] Выбор даты открывает системный календарь Chrome.
- [ ] TalkBack (по желанию): список пакета/комнаты, выбранный пункт, кнопка закрытия.

## Десктоп
- [ ] Окно по центру, не шире 32 рем, прокрутка колёсиком только внутри; полоса прокрутки страницы не пропадает и не сдвигает вёрстку при открытии.
- [ ] Клавиатура: Tab по полям, Enter на «Пакет» открывает список, стрелки меняют пункт, Enter выбирает, Esc закрывает только список, второй Esc закрывает форму, фокус возвращается на кнопку, которая её открыла.

## Если что-то прыгает
Записать модель телефона, версию iOS/Android, браузер, ориентацию, что делали (поле, клавиатура, прокрутка, панель браузера) и по возможности записать экран. По такому описанию проблему можно воспроизвести.
